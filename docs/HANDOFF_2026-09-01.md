### 3.4 Step 2B — eval-awareness control

Erasing the eval-awareness direction costs the limiting probe **0.0017 AUC**
(0.737 → 0.736), CI spanning zero, p vs null = .18. `cos(v_eval, v_limiting) = −0.093`,
inside the null band.

**Manipulation check is what makes this interpretable:** the same cross-fitted erasure
drives test-vs-deploy decodability **1.000 → 0.500**. The erasure demonstrably worked, so
the null is a real null.

Design points that carry it: cross-fitted (direction re-derived per training fold — a
globally-fit direction would over-remove on test and bias toward the answer we wanted);
null is 100 permuted-frame directions from the same pipeline, **not** isotropic randoms
(those cost ~0.0000 AUC because a random vector in 3584-d is near-orthogonal to the
manifold, so v_eval would beat them trivially); tuned decoder for the manipulation check.

### 3.5 A statistical correction that must be disclosed in methods

The first 2A run bootstrapped within a single CV repeat's folds while the reported
statistic averages 20 repeats, making intervals too wide. Corrected to resample scenarios
once per draw and recompute the full repeat-averaged statistic. **This moved the limiting
Holm p from .054 to .006, and the fix was made after seeing .054.** The fix is correct on
its own terms (bootstrap the estimator you report) and its direction was predictable a
priori; point estimates did not move. Both inferences are retained in `legacy_*` columns.
**Put this in the methods section — do not bury it.**

Also: `fast_auc` (Mann-Whitney U, average ranks) replaces `roc_auc_score` in the bootstrap
hot path, 28× faster, asserted identical to 1e-12 on 200 tie-heavy cases at every run.

## 5. What the paper can claim, and what it must not

**Can claim:**
1. Pre-response layer-20 activations predict upcoming disclosure-limiting strategy
   substantially better than the scenario wording (Δ +0.162, Holm p = .006).
2. This is specific to strategy rather than disclosure outcome (tested, p = .010 against
   substantive leak).
3. It is not evaluation-awareness (erasure control with a passing manipulation check).
4. The measurement-correction arc (old judge → evidence-span rubric v1.3 → the `refused`
   construct collapsing 36 → 7 → withdrawn 0.89 deflection AUC) is itself a contribution.

**Must not claim:**
- **"The activation contains information the text doesn't."** It is a deterministic
  function of the prompt. Correct wording: the model's processing makes behaviour-relevant
  information *linearly extractable* where text classifiers cannot extract it. This is the
  easiest way to lose the headline; see arXiv:2509.21344.
- **Δ unqualified.** It is relative to a baseline family (TF-IDF + one frozen encoder). A
  stronger encoder can only shrink it.
- **Anything causal.** Correlational decoding at one extraction point.
- **That rank-1 erasure removed a concept in full.**
- **258-population numbers as primary or as replication.** 258 ⊃ 216; the extra 42
  calibration cases are enriched (67% limiting, 62% leaked vs 35%/26%) and are the only
  human-verified references.
- **The old refusal/deflection 0.89–0.92 numbers.** Formally withdrawn — the construct
  dissolved, it did not merely shrink.

**Still-open caveats:** labels are single-judge and provisional; the judge prompt asserted
human verification falsely; one layer, one extraction point, one model.
