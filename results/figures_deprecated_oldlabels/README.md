# DEPRECATED FIGURES — built on superseded judge labels

These four figures (eight files) were generated by `scripts/make_figures_f.py` during
session 13, before the tier-3 label correction. **Every behaviour-conditioned number in them
is superseded.** They are retained for provenance, not for use.

Moved here from `results/figures/` on 2026-09-01 (rename, not regeneration — the bytes are
unchanged from the session-13 originals).

## Why deprecated

`docs/impact_judge_branch_2026-08-27.md` traces the GPT-4o-mini judge defect forward to every
downstream artifact and lists all four of these figures as label-dependent:

| figure | dependency | status |
|---|---|---|
| `fig1_asymmetry` | free-generation and forced-prefix behaviour curves | superseded — old labels |
| `fig2_dissociation` | deflection and leak bars + count-based CIs (the secret/public bar survives the judge but inherits the separate rewrite defect) | superseded |
| `fig3_null_coupling` | leaked/appropriate groups, n=128/73, quintile leak rates, AUC 0.421, χ²=0.68 | superseded — contaminated by **both** the judge and rewrite branches |
| `fig4_layer_trajectory` | both behaviour trajectories | superseded — old labels |

Additional specific problems:

- The `refused`/deflection construct these figures are built around **no longer exists**. Under
  the evidence-span rubric (`ci-disclosure-v1.3.0`) the class collapsed from 36 cases to 7 and
  is now unmeasurable; the old "deflection ≈ 0.89–0.92" headline is formally withdrawn
  (`docs/FULL_AUDIT_AND_NEXT_STEPS_f.md` §3 claim D).
- `fig1`'s position-sweep panels additionally cover only the first 64 response tokens of a
  median-111-token response (L15).
- `fig3`'s "slightly backwards" coupling trend was already flagged as fragile
  (projection AUC 0.421 → 0.486 after excluding failed rewrite pairs; session 16 §7).
